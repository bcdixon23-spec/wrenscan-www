What the beta checks on your Mac

13 security checks written for macOS

Each one answers a plain question about the Mac that Wrenscan runs on.

macOS versionIs this Mac still getting security updates from Apple?
FirewallIs the built-in firewall switched on?
FileVaultIs the disk encrypted, so a lost Mac can't be read?
GatekeeperIs the check that blocks unsigned apps on?
System Integrity ProtectionIs the protection for system files on?
Automatic security updatesDo security fixes install by themselves?
