What is SMBv1, and why should you turn it off?

25 November 2026 · 2 min read

SMB (Server Message Block) is how Windows computers share files and printers with each other. It has had several versions. The first, SMBv1, dates from the early 1990s and was designed long before today's threats.

Why it matters

In 2017 the WannaCry ransomware spread around the world in a few days, followed weeks later by NotPetya. Both used a flaw in SMBv1 (known as EternalBlue) to jump from one computer to the next on the same network, with no one clicking anything. One infected laptop could encrypt every vulnerable machine it could reach.

Microsoft patched that flaw, but SMBv1 itself remains old and unsafe by design, and modern Windows no longer needs it. Newer versions of Windows 10 and Windows 11 don't install it by default, but it can still be present on PCs that were upgraded from older versions, and on older NAS drives, printers and media devices.

How to check whether a Windows PC has SMBv1 on

Open PowerShell as administrator and run:

PowerShell
Get-SmbServerConfiguration | Select-Object EnableSMB1Protocol
Get-WindowsOptionalFeature -Online -FeatureName SMB1Protocol

If the first says True, or the second says State : Enabled, SMBv1 is on.

How to turn it off

In the same administrator PowerShell window:

PowerShell
Set-SmbServerConfiguration -EnableSMB1Protocol $false -Force
Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol

Restart when asked. Or, without commands: Start > type "Turn Windows features on or off" > untick SMB 1.0/CIFS File Sharing Support > OK.

Will anything break?

Usually not: modern Windows, macOS and Linux all use SMB2 or SMB3. The exceptions are old devices that only speak SMBv1, typically an old NAS drive or a printer's "scan to network folder" feature. If something stops working, check for a firmware update for that device that adds SMB2 support, rather than turning SMBv1 back on.

What about the other devices on your network?

A NAS drive, an old media box or a forgotten PC can still be offering SMBv1 to everything around it.
