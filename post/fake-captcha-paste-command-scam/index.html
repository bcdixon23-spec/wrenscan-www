The fake CAPTCHA that asks you to paste a command: how to check if it got you

26 November 2026 · 3 min read

Written 26 November 2026. We make Wrenscan, which is mentioned at the end.

You're on a website and a box pops up: "Verify you are human." Instead of clicking pictures of traffic lights, it gives you three steps:

  1. Press the Windows key + R.
  2. Press Ctrl + V.
  3. Press Enter.

It looks like a slightly odd CAPTCHA. It isn't. When you clicked the box, the page quietly copied a command to your clipboard. The three steps paste that command into Windows' Run box and run it.

Security researchers call this ClickFix. Microsoft says campaigns using it target thousands of devices around the world every day (Microsoft Threat Intelligence). Variants say "fix this error" or "update your browser" instead of "verify you're human", and newer ones ask you to paste into Windows Terminal or PowerShell instead of the Run box.

What the command does

It downloads and runs malware. The most common is a password stealer: it copies the passwords saved in your browser and your logged-in sessions, so it can get into accounts without the password. Some versions install remote-control tools that let someone back in later.

It works because you run the command yourself. A real CAPTCHA never asks you to open the Run box, a terminal or PowerShell. If any website asks you to paste something there, close the page.

How to check your PC (two minutes, free)

The Run box remembers what was typed or pasted into it.

  1. Press Windows key + R to open the Run box.
  2. Click the small down arrow at the right end of the text box. It lists recent commands.
  3. Look for anything you don't recognise, especially long lines containing powershell, mshta, curl, http, iex or a long jumble of letters.

If you're comfortable with Registry Editor, the same list is under HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\RunMRU.

Two limits: Windows doesn't record a command that failed to run, and the newer versions that use Windows Terminal or PowerShell leave nothing in the Run box. A clean Run box is a good sign, not proof.

If you find one

  1. Disconnect the PC from the internet (turn off Wi-Fi or unplug the cable).
  2. Run a Microsoft Defender Offline scan: Windows Security > Virus & threat protection > Scan options > Microsoft Defender Offline scan. The PC restarts to do it.
  3. From a different device you trust, change your passwords, starting with your email, then your bank and anything saved in your browser. Use "sign out of all devices" where it's offered, because stolen sessions keep working after a password change. Turn on two-step sign-in.
  4. Look for remote-control software you didn't install (AnyDesk, TeamViewer, ScreenConnect and similar) in Settings > Apps, and remove it.
  5. On a work PC, tell whoever looks after your IT. If you're not sure the PC is clean, reinstalling Windows is the safe answer.

Where Wrenscan fits
